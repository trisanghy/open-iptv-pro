## 🇻🇳 Tiếng Việt

Trình phát IPTV mã nguồn mở cho Windows và macOS: M3U, EPG, MultiView, ảnh kênh, kiểm tra và sửa luồng; hỗ trợ 8 ngôn ngữ.

Dự án mã nguồn mở cho Windows/macOS với danh sách M3U, EPG, MultiView 4 kênh, Snapshot, kiểm tra luồng nhiều vòng và tự chuyển link dự phòng. Bản 4.15 có 8 ngôn ngữ giao diện. Không cung cấp nguồn truyền hình hay thuê bao.

## 🇬🇧 English

Open-source IPTV player for Windows and macOS: M3U, EPG, MultiView, snapshots, stream diagnostics and repair; 8 languages.

An open-source Windows/macOS IPTV player with M3U playlist management, XMLTV EPG, four-channel MultiView, snapshots, multi-pass stream diagnostics and verified backup-stream failover. Version 4.15 offers eight interface languages. No TV channels or subscriptions are bundled.
