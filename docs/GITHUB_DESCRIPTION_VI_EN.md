# Open IPTV Pro — GitHub project description (VI/EN)

**Trang sử dụng trực tiếp (Web):** https://trisanghy.github.io/open-iptv-pro/  
**Tải bản Desktop v4.23.60:** https://github.com/trisanghy/open-iptv-pro/releases/tag/v4.23.60  
**Mã nguồn:** https://github.com/trisanghy/open-iptv-pro/tree/main

Open IPTV Pro là ứng dụng IPTV mã nguồn mở cho **Windows/macOS** với M3U/M3U8, nhiều nguồn, tự chuyển link dự phòng, tìm kiếm, yêu thích, thư mục, EPG, HLS/DASH, FFmpeg, PiP, MultiView, Snapshot, Timeshift, ghi hình, Cast/AirPlay tùy hệ thống, sao lưu và giao diện đa ngôn ngữ.

Bản Electron **v4.23.60** có **Whisper Live Caption thu âm liên tục theo đoạn 8 giây**, Live Translate chỉ hiện phụ đề ngôn ngữ đích trên video, Argos/Hy-MT2/Qwen3 offline theo nền tảng, và **TTS Piper/VieNeu đọc trọn câu** với điều chỉnh tốc độ và giảm âm lượng gốc. AI được tải theo lựa chọn, có quản lý dung lượng từng mô hình. MLX dành cho Mac Apple Silicon, không chạy trên Windows/Intel.

**Web Edition** là bản trình duyệt riêng, mở ngay không cần cài, hỗ trợ playlist, HLS/DASH tùy codec và CORS, EPG, PiP, yêu thích, Backup JSON và đồng bộ nếu được cấu hình. **Không** quảng cáo FFmpeg native, Whisper/MLX/VieNeu offline hoặc DVR local là chức năng Web.

**EN:** Open-source desktop IPTV player with M3U/HLS/DASH, EPG, picture-in-picture, multiview, FFmpeg, recording and offline AI translation/voice subtitles. Release v4.23.60 includes continuous eight-second Whisper recognition, target-only on-video translated captions and complete-utterance TTS. The hosted Web Edition is browser-limited and separate from the desktop application.
