# Open IPTV Pro v4.23.60 — English product description

**Play in browser:** https://trisanghy.github.io/open-iptv-pro/  
**Get prebuilt desktop installers:** https://github.com/trisanghy/open-iptv-pro/releases/tag/v4.23.60

Open IPTV Pro is an open-source media player for Windows and macOS. Organize M3U playlists and channel folders, switch primary/backup sources, explore EPG, play HLS/DASH with platform-appropriate engines, and use PiP, MultiView, snapshots, recording, timeshift, Cast/AirPlay and backup/restore where supported.

The v4.23.60 Electron desktop adds continuous eight-second Whisper speech recognition, a one-language translated subtitle display directly on video, selectable offline Argos / Hy-MT2 / Qwen3 translation and Piper/VieNeu translated voice with complete-utterance playback and adjustable original volume. MLX model choices require Apple Silicon; individual AI downloads consume disk/RAM and are optional. Live ASR, translation and synthesis are not guaranteed zero latency.

The [Web Online edition](https://trisanghy.github.io/open-iptv-pro/) is a separate, static browser player with M3U, compatible HLS/DASH, favorites, EPG, PiP, JSON backup and optional cloud configuration. Due to browser security/runtime limits it does not include native FFmpeg, desktop DVR, offline Whisper/MLX/VieNeu inference or unrestricted stream playback. The web guide is at https://trisanghy.github.io/open-iptv-pro/huong-dan.html.

**Source:** main branch; **Downloads:** GitHub Release v4.23.60 with macOS ARM64/Intel DMGs, Windows x64 Setup/Portable, source ZIP and SHA256SUMS. No streams are bundled; access only legally authorized sources.
