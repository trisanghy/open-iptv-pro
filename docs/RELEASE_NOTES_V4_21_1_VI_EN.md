# Open IPTV Pro v4.21.1 — Bản sửa tìm thiết bị AirPlay

## Tiếng Việt

- Thêm danh sách **thiết bị AirPlay trên macOS** bằng Bonjour (`_airplay._tcp`).
- Tách biệt danh sách AirPlay và Google Cast; không báo nhầm không có TV khi chỉ thiếu thiết bị Chromecast.
- AirPlay vẫn phát thông qua Safari, người dùng chọn đích AirPlay trên Safari.
- Giữ nguyên chức năng chỉnh URL nguồn M3U của v4.21.
- Bảo toàn bản Full: FFmpeg tích hợp, Timeshift, MultiView, Snapshot 32 luồng, EPG, Doctor và cập nhật phiên bản.
- Không thay đổi Android và iOS.

## English

- Discover compatible AirPlay receivers on macOS via Bonjour (`_airplay._tcp`).
- Display AirPlay and Google Cast devices separately and clarify discovery errors.
- AirPlay playback still uses Safari; users select the destination there.
- Retain v4.21 saved M3U URL editing.
- Full Edition remains intact, including bundled FFmpeg, Timeshift, MultiView, 32-worker snapshots, EPG, Doctor and update support.
- Android and iOS remain unchanged.

> This is a source release. Desktop installers require GitHub Actions build and compatible signing for seamless in-app update.
