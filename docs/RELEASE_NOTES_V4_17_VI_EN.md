# Open IPTV Pro v4.17.0 — Windows/macOS

## Tiếng Việt
- Thêm **Smart IPTV Doctor 2.0**: báo cáo điểm ưu tiên, bằng chứng phát thực tế và hoàn tác thay đổi gần nhất.
- Thêm **phát hiện khung hình đứng/màn hình đen** ở video đang xem. Chỉ cảnh báo; không đánh dấu link Die vì cảnh tĩnh. Có tùy chọn thử link dự phòng khi đứng hình đã xác nhận (mặc định tắt).
- Thêm **đối chiếu Snapshot bằng dấu vân tay hình ảnh** chạy tại máy, đề xuất cặp kênh nghi trùng. Không gộp tự động chỉ dựa trên một ảnh.
- Có **báo cáo JSON**, kiểm soát số ảnh mỗi lần quét, đề xuất sửa metadata và hoàn tác.
- Giữ EPG, MultiView, Yêu thích, 32 luồng kiểm tra/chụp, tự cập nhật và 8 ngôn ngữ.
- Chỉ dành cho **Windows/macOS**; chưa cập nhật Android/iOS.

## English
- Added **Smart IPTV Doctor 2.0** with prioritized diagnostics, evidence-based status suggestions and undo for the last change.
- Added **on-device frozen-frame and black-screen monitoring** for the current channel. Static scenes alone never mark streams as dead; confirmed freeze fallback is opt-in.
- Added **local snapshot perceptual comparison** to suggest possible duplicate channels; one similar frame never triggers automatic merging.
- Exportable JSON report, bounded image scanning, reviewed backup URL suggestions, existing 8-language UI and desktop features.
- **Desktop only**: Windows and macOS. Android/iOS sources are unchanged.

**Note:** A Release containing only source code cannot be installed using the built-in updater; publish installer assets and update metadata as documented.
