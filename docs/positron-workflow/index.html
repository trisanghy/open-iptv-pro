Lưu dữ liệu trên GitHub

Chỉ nhập token trên bản Site bạn tin cậy và tự kiểm soát, không nhập vào website HTML preview bên thứ ba. Fine-grained PAT chỉ cần quyền Contents: Read and write trong đúng repository. Token chỉ giữ trong RAM phiên này.

Chỉ thay docs/positron-workflow/data.json trên nhánh Positron. Lưu bằng SHA tệp để chống ghi đè thay đổi đồng thời.
