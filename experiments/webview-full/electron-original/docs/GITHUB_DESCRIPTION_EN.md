**Full description for project home / release notes:**

Open IPTV Pro is an open-source desktop IPTV player and playlist manager built with Electron for Windows and macOS. Import M3U playlists from local files or URLs, organize channels and favorites, view XMLTV EPG guides, use four-channel MultiView, capture thumbnails, and diagnose streams through multi-pass checks and backup-link failover. Version 4.15 includes an interface language selector with Vietnamese, English, Spanish, Portuguese (Brazil), Simplified Chinese, Thai, Lao and Khmer. The project is licensed under MIT and does not bundle TV channels or subscriptions. Android and iOS builds are not part of this desktop release.
