# v4.18.0 — Open IPTV Pro Lite

## Tiếng Việt
Tối ưu bộ cài riêng kiến trúc và loại bỏ FFmpeg nhúng. Khắc phục lỗi proxy tự ngắt luồng liên tục sau 25 giây; giảm RAM/băng thông HLS, tối ưu MultiView, gộp các thao tác Doctor trùng nhau. Timeshift/Snapshot hàng loạt yêu cầu cài FFmpeg ngoài. Giữ 8 ngôn ngữ và dữ liệu người dùng.

## English
Lean architecture-specific builds, optional external FFmpeg, fixed live-stream proxy timeout, lower HLS resource usage, and consolidated diagnostic controls. Bulk snapshots and timeshift require separately installed FFmpeg.
