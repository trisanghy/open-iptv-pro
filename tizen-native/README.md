# Open IPTV Pro TV Web Lab v0.1.53
Chỉ mở https://trisanghy.github.io/open-iptv-pro/ trực tiếp. Module GitHub: `trisanghy/open-iptv-pro@tizen-hybrid-experiment`. TizenBrew chính thức hỗ trợ packageType mods: https://github.com/reisxd/TizenBrew/blob/main/docs/MODULES.md
Không thay đổi player, giao diện hoặc dữ liệu website. Script bổ sung chỉ xử lý focus và remote, sử dụng các nút hiện có của web. Không AVPlay, không relay, không player riêng. Nếu metadata cũ vẫn cached, bootstrap cũ tải index mới và chuyển tới website; có thể cần xóa và thêm lại riêng module Lab để tải adapter remote.
WGT riêng là launcher web tối giản, không chứa engine riêng; cần ký và cài trên TV, điều hướng remote phụ thuộc web/runtime, không có script injection TizenBrew. Website dùng storage theo origin của chính website, không cam kết tách dữ liệu với cùng website đã mở trước đó. Bản chính tizenbrew không sửa. Chưa thử trên TV thật.
