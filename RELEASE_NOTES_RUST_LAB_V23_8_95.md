# Rust Lab v23.8.95 — Light empty-state and folder-action legibility

After reviewing screenshot comparisons for `v23.8.94`, two remaining Light inconsistencies were confirmed:
1. Empty channel and EPG messages generated by `.empty-list` still used the original pale dark-mode text color.
2. Folder actions (create, expand all, collapse all) still used a pale lavender text color and occasionally dark-mode hover color.

## Change
- Apply a readable dark slate text color to `.empty-list` only in Light mode, including dynamically inserted channel and EPG messages.
- Align channel folder action text, border, background and hover with the selected Light palette.
- Preserve the accent, native player, media overlay, app state, local models, Dark and AMOLED themes.

## Tests
- The Light visual audit captures 11 renderer pages and checks the selected channel tab contrast at WCAG 4.5:1.
- Rust Lab x64 EXE and macOS universal DMG must be verified from the immutable `rust-lab/v23.8.95` release CI before distribution.
