# Open IPTV Pro 4.15.0 — Internationalization (Desktop Only)

- New language selector in Settings: Vietnamese, English, Spanish, Portuguese (Brazil), Simplified Chinese, Thai, Lao and Khmer.
- Language choice persists locally and switches immediately without restart.
- Updated core UI strings in navigation, watching, playlist/source management, EPG, snapshots and settings.
- Added editable `renderer/locales/*.json` dictionaries and an offline localization runtime.
- Kept imported channel, folder and program-guide data unchanged.
- Replaced the repository README with an English project overview; added `docs/GITHUB_DESCRIPTION_EN.md` and English user documentation.
- Updated package and build metadata to version 4.15.0.
- Android and iOS code are not included or changed in this release.

**Known limitation:** Not every advanced technical message or rare dialog is translated yet. Contributors can improve dictionary coverage without modifying app logic.
