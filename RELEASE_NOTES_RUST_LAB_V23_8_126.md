# Rust Lab v23.8.126 — Real Smart download buttons and ONNX model inference

- **What the previous screen lacked:** a Smart dropdown listed model names, but no actual weights could be downloaded. The new Smart panel has **↓ Tải**, progress, installed status, and **Xóa** controls hooked to actual on-device ONNX model loading and per-model CacheStorage.
- **Two real, verified multilingual Smart models:** E5 Small INT8 (Xenova/multilingual-e5-small) and multilingual MiniLM INT8 (Xenova/paraphrase-multilingual-MiniLM-L12-v2), each ~118 MB weight file. Both are under the 200 MB limit including typical small tokenizer/config files. These are feature-extraction/embedding models; the app uses similarity against 17 Vietnamese topic descriptions to classify channel metadata and relevant EPG programmes. They are not generative chat models, nor fine-tuned supervised IPTV classifiers.
- **The small-model list is visible:** Standard now shows built-in Naive Bayes and the proposed fastText ~18 MB variant, honestly marked unavailable without verified `.ftz` weights. TinyBERT/MobileBERT/PhoBERT also remain visible in Smart, with precise unavailable states rather than inert fake download actions.
- **Only explicit downloads:** choosing Smart or changing selections will not download ONNX weights. Clicking the download button prompts for consent, fetches an allowlisted public model, performs a real ONNX forward-pass validation, and stores it in a model-specific browser cache. A local Transformers.js/WASM runtime is packaged during application build (version pinned, no runtime script CDN).
- **Automatic results:** once Smart is installed and selected, it reuses saved per-channel labels and runs on-device embedding inference only for new/changed channel metadata, plus currently relevant EPG programmes with new content hashes. Keeps existing WatchFlow Standard/Qwen3 scan-once behavior and folder state. Supports manual rescan.
- **Model deletion:** removes only the selected Smart model cache after confirmation, and preserves channel playlists/EPG and native MLX model directories. Other AI storage management remains intact.
- **Limits and testing:** actual Windows/macOS model weight download and WebView ONNX runtime performance require device validation; no weights are bundled, sizes are from verified public model repository listings. Source, UI interactions and cache boundaries have automated regression coverage. Failure shows a real error instead of falsely claiming installation.
- **Policy:** `experiment/rust-tauri-v2` only, immutable experimental tags; Windows/Mac installers in GitHub Actions Artifacts, not GitHub Releases/Stable. No other branches altered.
