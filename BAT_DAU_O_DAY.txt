OPEN IPTV PRO v4.15 — WINDOWS & MAC ONLY

1. Build Mac: double-click BUILD_MAC.command in this folder. macOS creates .dmg in dist/.
2. Build Windows: run BUILD_WINDOWS.bat. Windows creates Setup/Portable .exe in dist/.
3. Run source with Node.js 22+: npm install, then npm start.
4. In the app open Cài đặt (Settings) → Ngôn ngữ (Language).
   Choose Tiếng Việt, English, Español, Português, 简体中文, ไทย, ລາວ, ភាសាខ្មែរ.
5. Language choice is saved and changes immediately. M3U channel titles and EPG data are untouched.
