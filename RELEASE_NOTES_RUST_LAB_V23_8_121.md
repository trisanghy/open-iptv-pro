# Rust Lab v23.8.121 — WatchFlow channel AI scan-once + incremental EPG + stable folders (PRE-RELEASE)

- **Fix folder collapse during AI scan:** both channel-topic folders and programme-EPG folders retain their expanded state and pagination when cached/AI data updates. Qwen per-channel progress no longer replaces the entire result DOM while the user is browsing.
- **Scan each channel only once by default:** local Standard metadata categories and Qwen3 offline classifications are cached separately by stable channel identity (ID, name, group, tvg ID); they persist across restarts. Existing results load immediately without requiring a full reclassification. Only added/renamed channels automatically enter the AI queue.
- **EPG is independent:** when a new guide arrives, unchanged programme titles/descriptions keep their classification even when airing times change; only new content receives genre analysis. Removes the artificial 30-minute refresh that used to reclassify all channels. EPG updates do NOT enqueue Qwen3 on existing channels.
- **Manual ↻ Quét lại:** visible beside scan progress; intentionally ignores caches and recalculates channels and EPG. Intelligence mode also requests a fresh Qwen3 run. No clicking necessary for normal new-channel/new-EPG handling.
- **Data safety:** only channel/EPG labels and programme metadata are cached locally; stream URLs and credentials are not persisted by this subsystem or sent for Qwen/internet classification. Existing MLX model storage/download/delete controls remain functional.
- **Migration note:** first launch after this update establishes the new persistent local channel cache. Previously saved Qwen3 results are reused when the legacy metadata-based cache key matches; if EPG has already changed, a one-time new Qwen3 classification may be needed. Subsequent launches reuse stable results.
- **Testing:** regression covers cache restoration, no repeated inference, new-channel and changed-guide triggers, changed-airtime reuse, manual force, folder retention, and real per-channel model-cache identity.
- **Release policy:** experimental Rust/Tauri branch and immutable tags only. Build outputs in GitHub Actions artifacts, **not** Releases; Stable/Latest/main and other branches unchanged.
