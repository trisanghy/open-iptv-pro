# Rust Lab v23.8.117 — WatchFlow multi-topic folders, automatic Qwen3 coverage and EPG programmes (PRE-RELEASE)

- **Root cause fixed:** the old Qwen3 preview explicitly restricted inference to the first eight channels (`slice(0,8)`). This artificial limit is removed. When Intelligence is selected and a compatible Qwen3 model is installed, a single-worker background queue processes the available channels, prioritizing unknown subjects, caching results locally and reporting progress; it does not require a classify button. Inference may take considerable time for a large playlist.
- **Multiple genres per channel:** 17-topic category taxonomy; specific channel name metadata plus programme titles/descriptions; no forced one-label classification. Examples: Asian Food Network → Ẩm thực; An Ninh TV → Pháp luật/Tin tức; provincial TV → Địa phương/Truyền hình tổng hợp. Known channel branding takes precedence over conflicting Qwen guesses.
- **New WatchFlow folders:** "Thư mục chủ đề" (one channel can belong to many folders) and "Chương trình EPG" (individual matched programme entries grouped by topic and scheduled time). Expand folders to inspect items; show more without rendering the entire catalog at once. Selecting a channel to watch is still an explicit user action.
- **Internet fallback:** public-name-only Wikidata searches now prioritize unclassified channels with a bounded 72 lookups/day and caching, exact channel matching, multi-topic enrichment, and independent opt-out. No stream URLs, M3U contents, tokens, or viewing history are sent for these searches. Internet coverage is not guaranteed.
- **Honest local operation:** Standard Naive Bayes remains the automatic fallback for every loaded channel; Smart model catalog is not misrepresented as a working Transformer backend; Qwen3 reuses already installed native MLX weights only. No automatic new model downloads.
- **Native pipeline:** Qwen3 task returns validated JSON categories (up to four), preserving the existing primary "label" interface and all translation workflows. No changes to playback, playlist grouping, EPG sources or main.
- **Regression tests:** taxonomy, channel name cases from screenshots, individual EPG genres, folder membership, internet query prioritization and privacy, Qwen queue no-eight-limit, native JSON contract, and existing Rust Lab quick tests.
- **Branch/release policy:** experiment/rust-tauri-v2 only, immutable prerelease. Do not modify main/Stable/Latest or other branches. EXE/DMG availability requires actual CI success.
